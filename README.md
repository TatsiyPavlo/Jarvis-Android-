# Джарвіс — Android (тестовий проєкт)

Це **вихідний код**, а не готовий APK. Код не перевірявся на фізичному телефоні. Можливі помилки збірки й обмеження Android.

## Збірка тільки з телефона через GitHub
1. У браузері відкрийте github.com та створіть репозиторій (краще приватний).
2. Завантажте **вміст** цієї папки до кореня репозиторію, зокрема приховану `.github/workflows/android-apk.yml`. З телефону може знадобитися режим «Версія для ПК» або розпакування ZIP файловим менеджером.
3. Відкрийте вкладку **Actions**, виберіть **Build Jarvis APK** і натисніть **Run workflow** (або дочекайтеся автоматичної збірки після push).
4. Після успіху завантажте артефакт **Jarvis-debug-apk**, розпакуйте ZIP з артефактом і встановіть `app-debug.apk`.
5. Android може попросити дозвіл на встановлення з браузера/файлового менеджера; надавайте дозволи лише своєму власному APK.

## Що є
- Українське розпізнавання через системний SpeechRecognizer (`uk-UA`).
- Команди `відкрий <назва застосунку>`, `запусти <назва застосунку>`; можна сказати `Джарвіс, відкрий ...`.
- Ручний запуск та зупинка foreground service з видимим сповіщенням.

## Важливі обмеження
- Це **не** повноцінний постійно активний hotword-асистент. Android SpeechRecognizer не гарантує безперервного слухання або роботи з вимкненим екраном. Окремий механізм wake-word ще не реалізований.
- На Android 10+ запуск інших застосунків із фонового сервісу може блокуватися системою.
- Додаткові функції (ліхтарик, дзвінки, повідомлення, ШІ) ще не реалізовані.
- Для використання розпізнавання може знадобитися встановлений системний сервіс розпізнавання української мови.
